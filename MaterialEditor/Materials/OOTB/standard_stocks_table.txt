# This is a sample standard stocks table file. The main purpose of the file is to  
# describe how to set stock parameters so that it can be read successfully by NX. 
# The file uses comma , as a delimiter and can be stored/edited with a
# spreadsheet application.  File extension of .txt and .csv are valid.
#
# Following keywords are recognised by NX and should be used to used to
# define data that can be used by the nesting stocks.
# STANDARD_STOCKS_FILE_VERSION
# VERSION
# UNITS
# METRIC
# ENGLISH
# TABLE
# STOCK_NAME
# LENGTH
# WIDTH
# THICKNESS
# PHYSICAL_MATERIAL_NAME
# END_OF_TABLE
#
# The standard stocks table file is divided into 3 functional blocks.
##BLOCK1##
#
# This block determines the version of standard stocks table file. This will provide a clear upgrade path
# for future format changes to the file. It is important that version numbers are not edited. 
# The valid value for this release is:
# STANDARD_STOCKS_FILE_VERSION = 1
#
##BLOCK2##
#
# Contains the units of the parameters in the standard stocks table file. It can either be METRIC or ENGLISH.
# A table cannot have more than one unit. Two separate standards files can be used, one for each unit of measure.
#
##BLOCK3##
#
# Contains the actual standard stocks table. Start and end of a table is defined by TABLE and END_OF_TABLE keywords respectively.
# Table must have a version. This can be set using the VERSION keyword. Valid value for this release is:
# VERSION = 1.
#
# The first row, following table version, contains the names of the columns. 
# Columns STOCK_NAME, LENGTH, WIDTH, THICKNESS and PHYSICAL_MATERIAL_NAME are mandatory.
# 
# The second row decides the columns properties:  
# unique    - There must be one column with this identifier. This column should contain unique  
#             names of the stocks.  
# show      - These columns will be used for filtering data through UI when selecting a stock
# hide      - The values of these columns will be stored but will not be used for filtering data
#
# Each new line after column properties til END_OF_TABLE will be treated as a separate row containing stock information.
# Each stock should have an unqiue name defined under STOCK_NAME column, followed by length, width, thickness and a physical material
# separated by commas. Empty cells should contains at least one blank space character.
# 
# TABLE
# VERSION, 1
# STOCK_NAME,     LENGTH,    WIDTH,    THICKNESS, PHYSICAL_MATERIAL_NAME,
# unique,         show,      show,     show,      show,                  
# Stock1,         3000.0,    2000,     0.63,      Aluminum_2014,         
# Stock2,         3000.0,    2000,     1.6,       Aluminum_6061,         
# Stock3,         4000.0,    3000.0,   3.0,       Brass,                 
# END_OF_TABLE
#
#
# Disclaimer: THIS FILE DOES NOT CONTAIN ACTUAL DATA. PLEASE MODIFY THE TABLES
#             WITH ACTUAL VALUES BEFORE USING THIS TABLE. SIEMENS IS NOT RESPONSIBLE FOR THE
#             DATA CONTAINED IN THIS FILE. THIS FILE IS PROVIDED JUST AS A SAMPLE TO EXPLAIN
#             THE FORMATTING OF A TYPICAL STANDARD STOCKS TABLE FILE.
